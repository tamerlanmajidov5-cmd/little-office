# Little Office Game

**[Play Little Office Game online](https://tamerlanmajidov5-cmd.github.io/little-office/)** — free, with no download or account needed for the guest office.

A playful office simulation with five workers and one computer each, Pip the pet cat, a garden, gym equipment, and local mini games.

Explore the room, control Milo, Ava, Noah, Luna and Leo, visit the reading corner, and play games including chess, tic-tac-toe, memory and Toto's Star Quest.

This shared version opens only the office. It does not include the creator's ChatGPT conversation, personal messages, or account access.

The shared game has no connected live AI service. New AI replies and AI tasks need a separate service integration; they are unavailable in this public edition. Room controls and local games work without a ChatGPT account.

The trading desk is labeled **Market Simulation / Educational Analysis**. It does not place real-money orders or promise profit.

The website is published with GitHub Pages. [Visit the Little Office homepage](https://tamerlanmajidov5-cmd.github.io/).
