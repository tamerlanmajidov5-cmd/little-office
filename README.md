# Little Office

A playful office simulation with five workers and one computer each, a pet cat, a garden, gym equipment, and local mini games.

Explore the room, control the workers, visit the reading corner, and play games including Toto's Star Quest.

This shared version opens only the office. It does not include the creator's ChatGPT conversation, personal messages, or account access.

New AI replies and AI tasks require your own ChatGPT connection. Room controls and local games work without a ChatGPT account.

The trading desk is labeled **Market Simulation / Educational Analysis**. It does not place real-money orders or promise profit.

To publish with GitHub Pages, use the branch and folder containing `index.html` as the site's source. These files are prepared for publication; their presence alone does not confirm a live website.
